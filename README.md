Code, data and figures for my term paper (student ID 1776216). The paper tests whether BERT (bert-base-uncased and bert-large-uncased) handles negation in simple category sentences. For example, can it tell "A bee is an [MASK]" apart from "A bee is not an [MASK]"?

These experiments build on the NEG-136 diagnostic from Ettinger (2020), "What BERT Is Not: Lessons from a New Suite of Psycholinguistic Diagnostics for Language Models".
